# BanjirReady release update
The current public application has a premium responsive design and no demo-mode banner.
It uses official METMalaysia/data.gov.my forecasts for all 13 states and 3 federal territories, and current weather bulletins when the official feed provides valid active intervals.
JPS river/rainfall information and JKM relief-centre information are official portal links; those datasets are not ingested.
NADMA preparation guidance is source-linked and dated. The browser guidance assistant is rule-based, not generative AI.
Agency controls open phone diallers only.
See README.md for run instructions, sources and limitations.
Historical demo tests and fixtures remain isolated from the public UI.
